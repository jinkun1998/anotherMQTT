# anotherMQTT

Modern, cross-platform MQTT 5.0 desktop client for macOS, Windows, and Linux.

## Features

- Full MQTT 5.0 and 3.1.1 specification support.
- Cross-platform: macOS (Apple Silicon & Intel), Windows, and Linux.
- Payload formats: JSON, Plaintext, Hex, Base64, CBOR.
- Scripting and simulated traffic generator.
- Multi-connection workspace.

## Installation

Download pre-built binaries from the [Releases](https://github.com/jinkun1998/anotherMQTT/releases) page:

- **macOS**: `.dmg` (If blocked by Gatekeeper: `xattr -cr /Applications/anotherMQTT.app`)
- **Windows**: `.exe` installer or portable
- **Linux**: `.AppImage`, `.deb`
